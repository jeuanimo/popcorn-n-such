{# ── Catalog & Inventory ── #}

Catalog & Inventory

Use Products to create and edit product listings, descriptions, images, and pricing. Each product has one or more SKUs (size/variant combinations) that track individual inventory counts.

Use SKU Management to update stock quantities and set low-stock alert thresholds. When a SKU hits its threshold the fulfillment dashboard flags it.

Use Suppliers for vendor records and CSV bulk import. Supplier records link to purchase orders and help track replenishment.

{# ── Orders & Fulfillment ── #}

Orders & Fulfillment

Use All Orders to search by order number, customer name, or email, and to update order status. Status transitions (Paid → Processing → Packed → Shipped → Delivered) drive what actions are available to staff and customers.

Use the Fulfillment Dashboard to see orders that are ready to pick, pack, and ship, along with low-stock alerts and open label issues.

{# ── Shipping Labels ── #}

Shipping Labels

Generating a label

  1. Go to Shipping → Generate & Print Label.
  2. Select the order from the dropdown (only paid/in-progress orders appear).
  3. Choose a carrier/service — USPS Ground Advantage, FedEx Ground, or UPS Ground.
  4. Click Generate Label. The Pitney Bowes API is called and the label opens for printing.

Draft labels (no carrier credentials yet)

If Pitney Bowes credentials are not configured, the system automatically creates a Draft Label — a printable address label (PDF) with a "DRAFT — No Tracking Number" banner. Use the browser's Save as PDF option to keep a copy. Replace it with a real label once API credentials are set up in Operational Settings.

Label Monitor

Go to Shipping → Label Monitor to search all labels by tracking number or order number. From here you can:

  • Print — open the label PDF in the browser print dialog
  • Download — save the PDF to disk
  • Reprint — re-serve the label and log the reprint in the audit trail

Thermal printer via QZ Tray (one-time setup per workstation)

  1. Download and install QZ Tray on the computer at the store (free Java app).
  2. In Operational Settings → Label Printer, enter the Printer Name (must match the OS print spooler exactly, e.g. ZDesigner GK420d) and the printer's IP address.
  3. On the Generate & Print page, follow the QZ Tray Setup card: click Install Library (one-time), then start QZ Tray on the workstation, then click Connect to QZ.
  4. Labels with ZPL data will now print directly to the thermal printer without a browser dialog. If QZ Tray is unavailable the page falls back to browser PDF printing automatically.
{# ── Shipment Tracking ── #}

Shipment Tracking for Buyers

Customers see a live tracking timeline on their order detail page. They can click Refresh Status to fetch the latest scan from Pitney Bowes (results are cached 5 minutes).

Customers receive automatic email notifications when their package is Out for Delivery or Delivered. Emails use the SMTP settings configured in Operational Settings.

Webhook (automatic push): In your Pitney Bowes account, configure the tracking webhook URL to https://<your-domain>/shipping/webhooks/tracking/. PB will push scan events in real time. Set the SHIPPING_WEBHOOK_SECRET environment variable and configure PB to send it in the X-PB-Webhook-Secret header to verify requests.

{# ── Campaigns & Teams ── #}

Campaigns & Teams

Campaigns go live immediately by design. Use the Campaign Monitoring Queue to review any auto-flagged issues.

Use the Kill Switch to pause a campaign instantly, and Restore Live to re-enable it. Only paid orders count toward fundraising totals — cancelled and refunded orders are excluded automatically.

{# ── Site Content (CMS) ── #}

Site Content (CMS)

Use Site Configuration → Content Blocks to create and edit the editable sections that appear on public pages (hero banners, promotional callouts, testimonials, etc.) — no code changes required.

Each block has a Page (which page it appears on), a Section Name (internal key, e.g. hero or promo-banner), heading text, body text, an optional image, and an optional call-to-action button. Use Display Order to control the sequence and the Active toggle to show or hide a section without deleting it.

Use Notification Center and Alert Preferences to manage internal staff alerts (e.g. label printed, low stock).

{# ── Operational Settings ── #}

Operational Settings

Go to Staff Portal → Operational Settings. All changes take effect immediately — no server restart needed. Secret fields are never shown back; leave blank to keep the current value.

Business / Ship-From Address

Enter your store or warehouse address here. This is what appears in the FROM field on every shipping label. Fill in Business Name, Street Address, City, State (2 letters), ZIP, and Country (2 letters).

Shipping Provider & Rates

  • Shipping Provider — Pitney Bowes for live carrier rates; Flat Rate for a fixed charge with no API
  • Default Package Weight — used when item weight is unknown
  • Flat / Fallback Rate — charged on Flat Rate mode or when the live API fails (enter in cents: 899 = $8.99)
  • Free Shipping Threshold — orders at or above this subtotal ship free (7500 = $75; set 0 to disable)

Label Printer (QZ Tray)

  • Printer Name — must match exactly how the printer appears in the OS print spooler or QZ Tray
  • Printer IP — network IP for reference; configure in QZ Tray's printer settings

Pitney Bowes API

  • Enter your API Key and API Secret from the PB developer portal
  • Set Environment to sandbox for testing, production for live shipments

GoDaddy Payments

Enter API Key, Merchant ID, Webhook Secret, and API endpoint paths as supplied by GoDaddy. The webhook URL to register in GoDaddy's dashboard is shown at the bottom of the GoDaddy section — copy it from there.

Email / SMTP

Configure Contact Email, Default From Email, and your SMTP credentials. These settings power all transactional emails — order confirmations, tracking notifications, and password resets. Click Save Operational Settings for changes to take effect.

{# ── Customer Subscriptions ── #}

Customer Subscriptions

Customers can subscribe to repeat orders from any order detail page. Intervals available: Weekly, Every 2 Weeks, Monthly, Every 2 Months. Customers can pause, resume, or cancel subscriptions from their account.

Subscription renewal orders are created automatically on the scheduled date. Cancelled or paused subscriptions do not generate new orders. Staff can view all subscriptions via the Django admin panel.

{# ── Access & Users ── #}

Access & User Management

Admin users can use Create User in the staff portal to add a new portal account, set the user's initial password, and assign roles and permissions.

Roles available: admin, staff, organization_manager, team_captain, seller, customer. Role assignments control which dashboards, orders, and settings a user can access. All sensitive actions (label creation, reprints, settings changes) are logged in the security audit trail.
